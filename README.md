# sonic-libmlx
Molex SAI/OTAI and HAL libraries

Each directory contains debian packages needed to build SONiC sonic-ot-molex platform

## Branch ocs-hongruz (personal build branch, CARMEL hal: 544x544 and ocs-13ru platforms)

Branched from `ocs544` (7172ad9) for builds of sonic-buildimage-molex `ocs-hongruz` with
`MOLEX_DEV_TYPE=ocs-hongruz`. Not a release branch.

All four debs were built from sonic-mlx-debs ocs-hongruz aa13cd0 (2026-11-10), for sonic-buildimage-molex ocs-hongruz bdba96f6d (tested on a QOCS144 in image ocs-qocs144-aa13cd0-bdba96f6d). The 0ce3aba debs (ddde8fd, allied-vision 1.0.3) went with 986b109a5. The 10-30 release QOCS144-2026-10-30 used the 533bd37 debs (3357022). The release QOCS144-2026-10-14-Release used the c624f53 debs of 1abe6d8.

An image build of sonic-buildimage-molex `ocs-hongruz` also needs `INCLUDE_EXTERNAL_PATCHES=y` (the platform kernel config in
`platform/ocs-molex/non-upstream-patches`, e.g. `CONFIG_IGC=m`); its default is `n`.

The image recipe must ask for `allied-vision-1.0.9` (`platform/ocs-molex/allied-vision.mk`, sonic-buildimage-molex
ocs-hongruz bdba96f6d or later); the liboplkocs here does not load with 1.0.3 or 1.0.2. `libhal-mlx-model-1.1.0` is the unchanged `ocs544` copy (not
used by the ocs-molex image). These debs are CARMEL-only: do not use them on an OCS-2RU.
